Terratile

3D Maps for your Apps. An engine-agnostic runtime for streaming Photorealistic 3D Tiles, with a PlayCanvas integration.

Apache-2.0 @nam-digital-twins/terratile PlayCanvas beta
View live demo API reference GitHub npm
Live tile streaming with smooth, hole-free refinement.

Features

Any 3D Tiles source

Google Photorealistic 3D Tiles, Cesium ion, or tileset URLs through one interface.

Smooth streaming

Atomic refinement with a dither cross-fade. Detail sharpens as you move, without holes.

PlayCanvas integration

Drop tiles into your scene, anchored to a real-world location, with one script.

Ground snapping

Keep your entities glued to the tile surface as it refines and reloads.

Clipping and cutouts

Crop tiles to a polygon or punch holes in them, with smooth shader edges.

Tile caching

In-memory and optional persistent cache for fast revisits.

Live demos
